# Xion v30 Release Notes

## Overview

The Xion v30 release schedules the next testnet software upgrade and adds Verona-facing denomination metadata aliases while preserving existing XION identifiers and protocol-facing denominations.

## What's Changed

### Verona Rebrand Metadata

- Added Verona-facing aliases to the existing `uxion` bank denomination metadata.
- Preserved the base denomination `uxion`.
- Preserved display denomination `XION`.
- Preserved token name `xion`.
- Preserved token symbol `XION`.
- Preserved existing aliases such as `microxion`, `millixion`, and `xion`.

Alias additions:

- `uxion`: adds `uverona` and `microverona`.
- `mxion`: adds `mverona` and `milliverona`.
- `XION`: adds `verona` and `VERONA`.

### Upgrade Handler

- Bumped the upgrade handler name to `v30`.
- Runs standard module migrations.
- Keeps the v29 testnet cleanup for the JWK audience `poc-leaked-private-key` and its audience claim.
- Applies the Verona alias migration idempotently so aliases are not duplicated if the helper is run more than once in tests.

## Compatibility

This release does not rename:

- Chain ID
- Bech32 prefixes
- Module names
- Protobuf packages
- REST paths
- Account balances
- Staking denomination
- Mint denomination
- Gas denomination
- Base denomination `uxion`
- Display denomination `XION`
- Token name `xion`
- Token symbol `XION`

Verona aliases are informational denomination metadata. They do not create a new spendable base denomination; on-chain coins remain `uxion`.
