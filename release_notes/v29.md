# Xion v29 Release Notes

## Overview

The Xion v29 release focuses on ZK and DKIM hardening, Gnark Groth16 support, dependency upgrades, and release pipeline fixes. The recommended version is v29.0.1.

## What's Changed

### Security and Validation

- Added panic recovery guards around ZK and DKIM external crypto library calls.
- Added panic recovery to Gnark proof verification.
- Applied JWK key size validation and JWK `kty`/`alg` consistency checks during genesis validation.
- Fixed a Poseidon zero-field collision issue.
- Added gas metering for ZK and DKIM proof verification queries.
- Added ZK proof and public input size limits with governance floor validation.
- Enforced a static 1024-bit RSA minimum for DKIM and removed the `MinRsaKeyBits` governance parameter.

### ZK and DKIM

- Added Gnark Groth16 support.
- Added a `ProofSystemGnark` enum alias.
- Added support for verifying JWS in addition to JWT and returning JWT values.
- Transferred `AudienceClaim` ownership when `UpdateAudience` changes the audience admin.
- Removed the testnet JWK audience containing leaked RSA private key material from the v29 upgrade path.

### Dependencies

- Bumped wasmd to v0.61.9-xion.1.
- Bumped wasmd to v0.61.10.
- Upgraded `barretenberg-go` to v0.2.0.

### Operations and CI

- Fixed globalfee bypass minimum gas price clearing when the local minimum is already zero.
- Improved release artifact placement in GoReleaser.
- Extracted Linux binaries from Docker images for release packaging.
- Switched CI release runners to Ubicloud and removed the Depot dependency.
- Skipped Homebrew publishing when release publishing is disabled.
- Removed the 48 MB Barretenberg build cache from git.
