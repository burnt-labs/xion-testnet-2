# Xion v32 (Bakula) Release Notes

## Overview

Xion v32, codename Bakula, moves xion-testnet-2 to Cosmos SDK v0.55, CometBFT v0.40, ibc-go v11 and wasmd v0.70, and adds ML-DSA-65 (NIST FIPS 204) post-quantum signatures for native account keys. Testnet runs the release candidate `v32.0.0-rc1`; mainnet follows with `v32.0.0`.

## What's Changed

### Dependencies

- Cosmos SDK v0.55 (store v2), CometBFT v0.40.
- ibc-go v11, pinned to commit `2757a8778d05` because no tagged ibc-go release supports SDK v0.55 yet.
- wasmd fork `burnt-labs/wasmd v0.70.5-xion.4`, wasmvm v3.0.9.
- tokenfactory fork `v0.55.0-xion.1`.

### Upgrade Handler

- Upgrade name `v32`.
- Deletes the `group`, `nft`, `circuit` and `crisis` stores.
- Runs the module migrations: globalfee and jwk params move out of `x/params` into their own modules; mint, PFM, staking and auth migrate.
- Migrates IBC channel send sequences to the ibc-go v11 layout.
- On xion-testnet-2, registers the address entries of accounts instantiated under code 1880's checksum.

### New Parameters

- auth `sig_verify_cost_mldsa65` = 750.
- staking `key_rotation_fee` = 1 XION (SDK default; validator consensus-key rotation).
- mint `max_supply` = 0 (no cap).

## Node Operators

- With Cosmovisor, place the binary at `upgrades/v32/bin/xiond`; `releases/v32.json` lists the binaries with checksums.
- Existing `config.toml`, `app.toml` and goleveldb data directories open unchanged. There is no DB migration step.
- Defaults that only apply to freshly generated configs: `mempool.max_tx_bytes` 1 MB → 4 MB, `p2p.flush_throttle_timeout` 100 ms → 10 ms, new `event_bus_buffer_capacity`.
- `/status` reports `tendermint_version` 0.39.0.
- The first start recompiles contracts once (new Wasmer module-cache directory), so it is slower on nodes with many contracts.
- Source builds need Go ≥ 1.26.10. Release Linux binaries are fully static.

## Integrators (breaking)

- Accounts created after the upgrade get account numbers ≥ 2^63. CosmJS ≤ 0.38 throws on them; use CosmJS ≥ 0.39 with bigint account numbers.
- CometBFT v0.40 reports version `0.39.0`; CosmJS ≤ 0.37 picks the wrong RPC adaptor.
- Removed: gov v1beta1 queries (use gov v1), the `x/params`, group, nft, circuit and crisis endpoints (REST returns 501), and `SIGN_MODE_TEXTUAL`.
- globalfee and jwk params change through `MsgUpdateParams`, not `ParameterChangeProposal`.
